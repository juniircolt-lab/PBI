# Órbita

Controle local de demandas com dashboard, tabela editável, cartões, calendário e opções personalizáveis.

**[Baixar a versão atual](https://github.com/juniircolt-lab/PBI/raw/refs/heads/main/Orbita.zip)**

Extraia o ZIP inteiro, abra a pasta **Orbita** e dê dois cliques em **index.html** no Chrome ou Edge. Antes de trocar uma versão anterior, exporte um backup completo. Importe esse backup na nova versão em **Assistente e dados**.

## O que mudou

- Visual editorial com contraste, tipografia ampla, destaque cítrico e ilustração orbital própria.
- Botões **+** nos campos da tabela para criar status, áreas, projetos e prioridades sem sair da atividade.
- Botão **+** de prioridade em cada cartão e uma ação para adicionar colunas de status.
- **Seu fluxo** permite renomear opções, mudar cores e comportamento dos status e remover opções livres.
- Categorias personalizadas seguem no backup. Backups antigos são importáveis; backups com novas categorias devem ser usados nesta versão ou posterior.

O aplicativo funciona sem dependências externas. Os dados ficam no navegador ou em pasta conectada por você. Não há sincronização com o GitHub, Google Drive ou servidor.
